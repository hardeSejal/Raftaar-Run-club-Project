# 🏃‍♂️ Raftaar Run Club

Raftaar Run Club is a modern community-driven running platform designed to bring runners together through movement, consistency, and competition.

Built with a bold, high-energy aesthetic inspired by modern sports brands, the platform features:

* ⚡ Smooth GSAP-powered animations
* 🏃 Strava integration
* 📊 Dynamic leaderboard system
* 📅 Community event showcase
* 📸 Interactive gallery sections
* 🌙 Premium dark-themed UI

---

# 🚀 Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* GSAP
* Supabase
* Strava API

---

# ✨ Features

* Connect Strava account

* Live leaderboard tracking
* Smooth scrolling experience
* Fully responsive modern UI
* Event & community showcase

# 📦 Installation

```bash
npm install
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

VITE_STRAVA_CLIENT_ID=your_client_id
VITE_STRAVA_CLIENT_SECRET=your_client_secret
```

---

# ▲ Deployment (Vercel)

1. Push project to GitHub

```bash
git add .
git commit -m "Initial deployment"
git push
```

2. Import repository into Vercel

3. Add Environment Variables inside Vercel

4. Deploy project

5. Update Strava App settings:

Website:

```txt
https://your-project.vercel.app
```

Authorization Callback Domain:

```txt
your-project.vercel.app
```
